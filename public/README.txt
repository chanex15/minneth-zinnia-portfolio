Drop your media files DIRECTLY into this /public folder using the
EXACT file names below (same names as the GitHub repo).

The website will automatically pick them up — no code changes needed.

────────────────────────────────────────────────────────────────
  FILE          WHAT IT IS
────────────────────────────────────────────────────────────────
  P1.jpg        Your profile / headshot photo (shown in the hero)
  image1.jpg    Portfolio image 1  — Instagram Carousel
  image2.jpg    Portfolio image 2  — Brand Visual
  image3.jpg    Portfolio image 3  — Content Design
  V1.mp4        Portfolio video 1  — Reel / Shorts
  V2.mp4        Portfolio video 2  — UGC Style
  V3.mp4        Portfolio video 3  — AI Assisted
────────────────────────────────────────────────────────────────

TIPS
  • Use JPEG (or WebP) for images, MP4 (H.264) for videos.
  • Portrait / vertical (9:16) works best for the videos.
  • Keep each video under ~50MB for fast loading.
  • If a file is missing, the site shows a styled placeholder
    instead of breaking — so you can add them one at a time.

You can delete this README.txt file whenever you like.
